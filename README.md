# Portfólio - Trabalho final

Este repositório contém o site pessoal desenvolvido como trabalho final da disciplina de Construção de Sites da Universidade Federal de Santa Maria (UFSM).

O objetivo do projeto é demonstrar conhecimentos em desenvolvimento web front-end, criando um portfólio online para apresentar projetos, habilidades e experiências profissionais.

## Tecnologias utilizadas
- HTML5: Estruturação semântica das páginas.
- CSS3: Estilização, layout com Flexbox e design responsivo.
- JavaScript: Interatividade, incluindo modo escuro e validação de formulário.

## Estrutura do projeto
- index.html: Página inicial com apresentação, sobre mim, habilidades e experiência.
- paginas/projetos.html: Lista de projetos desenvolvidos com links para o GitHub.
- paginas/contato.html: Formulário de contato e links para redes sociais.
- css/style.css: Arquivo de estilos global.
- js/script.js: Scripts.

## Funcionalidades
- Navegação entre páginas.
- Modo escuro (Dark Mode) com persistência de preferência.
- Formulário de contato com validação de campos obrigatórios.
- Layout adaptável para diferentes tamanhos de tela.

## Como visualizar
Para visualizar o projeto, basta baixar os arquivos e abrir o arquivo index.html em qualquer navegador web.
